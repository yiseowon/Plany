# Plany 2.3.0 패치 노트

출시일: 2026-07-28

## 한눈에 보기

일본처럼 Google 개발자용 경로 API가 대중교통 데이터를 돌려주지 않는 지역에서도 사용자가 막히지 않도록 개선했습니다. Plany가 자체 노선 카드를 만들 수 없는 경우에는 공식 Google 지도 대중교통 화면을 이동경로 창 안에서 곧바로 보여줍니다.

## 달라진 점

- 빈 결과 안내 대신 실제로 조작할 수 있는 Google 대중교통 지도를 표시합니다.
- 출발지와 목적지는 사용자가 선택한 두 장소의 정확한 좌표로 연결합니다.
- 지도를 불러오는 동안 Plany 스타일의 로딩 화면을 제공합니다.
- 현재 구간을 한눈에 확인할 수 있는 장소명과 `크게 보기` 버튼을 추가했습니다.
- 기존의 차량·택시 및 도보 비교 카드는 그대로 유지합니다.
- 데스크톱 이동경로 창을 넓히고 모바일 지도 높이를 키워 터치 조작을 편하게 만들었습니다.

## 보안과 운영

- Google 지도 화면을 긁거나 노선 정보를 별도로 저장하지 않습니다.
- Google이 공식 지원하는 Maps Embed API와 Maps URL만 사용합니다.
- Google Cloud에서 Maps Embed API를 활성화했습니다.
- API 키는 Maps Embed API를 포함한 6개 API만 허용하며, 기존 GitHub Pages 및 로컬 웹사이트 출처 제한을 그대로 적용합니다.

## 업로드 상태

- 로컬 버전만 준비합니다.
- 사용자 확인 전에는 GitHub에 업로드하지 않습니다.
