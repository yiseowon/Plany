# Plany 2.1.0 패치 노트

작성일: 2026-07-28  
상태: 로컬 개발판 — GitHub 및 실제 서비스 미반영

## 일정 정렬 수정

- 장소를 추가하면 지정한 시간 기준으로 즉시 오름차순 정렬됩니다.
- 장소 시간을 수정해도 하루 일정 전체가 다시 시간순으로 정렬됩니다.
- 같은 시간인 장소끼리는 기존 순서를 유지합니다.
- 시간이 없거나 잘못된 옛 데이터는 일정 마지막에 배치합니다.
- 여행을 처음 열 때 예전에 저장된 순서도 한 번 자동 보정해 Firestore에 저장합니다.
- 시간 변경 후 장소 목록, 지도 경로, 일정 분석 카드가 함께 갱신됩니다.

## 이동경로 상세 개편

지도 경로선의 `INFO` 버튼을 누르면 다음 정보를 한 화면에서 확인할 수 있습니다. 단, 실제 표시 범위는 지역 교통사업자가 Google에 제공한 데이터에 따라 달라집니다.

- 실제 여행 날짜와 앞 장소의 방문 시간 기준 조회
- 전체 출발·도착 시각, 소요 시간, 거리
- 환승 횟수와 구간 수
- 실제 운임 정보가 제공되는 경우 해당 운임
- 버스·지하철·열차 등 차량 종류
- 노선 번호, 노선명, 운행 번호
- 행선지 또는 방면
- 승차·하차 정류장 이름과 시각
- 정거장 수와 배차 간격
- 운영 교통기관
- 승·하차 정류장의 정확한 Google 지도 위치
- 각 도보 구간의 시간과 거리
- 차량·택시 및 전체 도보 대체 경로
- Google이 제공하는 보행 및 경로 주의사항

기존의 일본 엔화 고정 택시비 계산은 국가에 따라 틀린 정보를 만들 수 있어 삭제했습니다. 관련 사이트 버튼도 그날 마지막 장소 검색이 아닌 현재 선택한 두 장소의 Google 지도 대중교통 길찾기로 교체했습니다.

## 실제 날짜 처리

- 미래 여행은 선택한 여행일과 방문 시간을 그대로 사용합니다.
- 이미 지난 여행일 또는 지난 시간은 Google 대중교통 API가 과거 조회를 지원하지 않으므로 현재 시각 직후의 운행정보로 대체하고 화면에 그 사실을 표시합니다.

## 여행 내부 레이아웃

- 데스크톱 사이드바 너비를 화면 비율에 맞게 유동적으로 조정합니다.
- 태블릿 크기에서도 지도와 일정이 좌우로 유지됩니다.
- 휴대전화에서는 지도가 전체 일정 아래로 떨어지지 않고 여행 제목 바로 아래로 이동합니다.
- 지도 아래에 날씨, 기능 탭, 날짜, 검색, 일정이 자연스럽게 이어집니다.
- 지도 크기가 바뀌면 Google 지도도 즉시 다시 계산하도록 연결했습니다.
- 내부 탭에 아이콘을 추가하고 여행 제목 아래에 선택한 날짜와 목적지를 표시합니다.

## 검증

- 시간 정렬 안정성 테스트
- 미래 여행 날짜 계산 테스트
- 지난 시간의 안전한 대체 조회 테스트
- 버스 번호·정류장 좌표·운임 파싱 테스트
- 기존 보안·버전·날짜·시간 테스트 전체 회귀 검증

## 기술 메모

경로 계산은 이제 Google Maps의 최신 `Route.computeRoutes` API를 먼저 사용합니다. 연결된 Google Cloud 프로젝트에서 Routes API가 아직 활성화되지 않은 경우에는 화면이 깨지지 않도록 기존 `DirectionsService`로 자동 전환합니다. Routes API를 활성화하면 별도 코드 변경 없이 최신 방식이 우선 적용됩니다.
