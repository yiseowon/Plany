# Plany 1.3.0 패치 노트

상태: 로컬 개발 및 검증 중  
기반 버전: `v1.2.0`

## 날짜 선택 경험 개편

- 브라우저가 제공하는 작은 기본 날짜 입력창을 제거했습니다.
- 출발일과 도착일을 하나의 큰 월간 달력에서 선택합니다.
- 출발일, 도착일, 그 사이 기간이 이어진 형태로 표시됩니다.
- 선택한 날짜는 `월·일·요일` 형식으로 즉시 확인할 수 있습니다.
- 오늘 날짜를 달력에서 구분합니다.
- 이전 달과 다음 달을 큰 버튼으로 이동할 수 있습니다.
- 출발일 또는 도착일 영역을 눌렀을 때 해당 단계부터 선택합니다.

## 빠른 기간 선택

- 오늘
- 이번 주말
- 3박 4일
- 일주일

## 아이폰 크기 최적화

- 작은 화면에서는 달력이 화면 아래에서 올라오는 시트로 표시됩니다.
- 홈 인디케이터 영역을 고려한 하단 여백을 사용합니다.
- 버튼과 날짜 셀을 손가락으로 누르기 쉬운 크기로 조정했습니다.
- 달력이 열려 있을 때 뒤쪽 화면 스크롤을 막습니다.

## 검증과 접근성

- 90일을 넘는 기간은 선택 단계에서 즉시 안내합니다.
- 잘못된 날짜 범위는 저장 전에 다시 검증합니다.
- Escape 키와 바깥 영역 클릭으로 달력을 닫을 수 있습니다.
- 날짜마다 한국어 접근성 이름과 선택 상태를 제공합니다.
- Firebase에는 기존과 동일한 `YYYY-MM-DD` 형식으로 저장하므로 이전 데이터와 호환됩니다.
