# Plany 2.0.0 패치 노트

작성일: 2026-07-28  
상태: 로컬 개발판 — 아직 GitHub에 업로드하지 않음

## 한눈에 보기

Plany 2.0은 기존 기능을 조금 다듬는 수준이 아니라, 처음 방문한 사람이 서비스의 가치를 이해하고 안심한 뒤 여행 계획을 시작하도록 전체 흐름을 다시 설계한 버전입니다.

## 사용자 화면

- 로그인 상자를 제품 소개형 랜딩 페이지로 전면 교체했습니다.
- 지도·일정, 비용 정산, 공동 체크리스트의 핵심 가치를 첫 화면에서 설명합니다.
- 실제 여행 계획에 도움이 되는 자체 여행 팁 영역을 추가했습니다.
- 날짜 바로가기 이름을 `오늘부터 3박 4일`, `오늘부터 일주일`로 명확하게 변경했습니다.
- 브라우저 기본 시간 입력을 없애고 큰 글씨, 5분 단위 조절, 추천 시간 버튼이 있는 전용 시간 선택기를 추가했습니다.

## 동의와 개인정보

- 이용약관과 개인정보 처리방침 필수 확인 화면을 Google 로그인 전에 추가했습니다.
- 필수 항목을 모두 선택해야 계속할 수 있습니다.
- 동의한 약관 버전과 시각을 브라우저 및 본인만 읽고 쓸 수 있는 전용 계정 문서에 기록합니다.
- 동의를 취소하면 로그인 흐름이 중단됩니다.
- 이용약관, 개인정보 처리방침, 광고·쿠키 안내 문서를 추가했습니다.

> 법률 문서는 현재 초안입니다. 운영자 이름·연락처·개인정보 담당자·실제 데이터 처리 흐름을 확정하고 전문가 검토를 받은 후 공개해야 합니다.

## 팝업 편의성

- 새 여행, 여행 설정, 프로필, 장소 추가, 장소 편집, 경로 정보, 장소 추천 화면에 취소 또는 닫기 버튼을 추가했습니다.
- 일반 팝업은 바깥 영역 또는 Esc 키로 닫을 수 있습니다.
- 반드시 명시적으로 선택해야 하는 최초 동의 화면은 바깥 클릭이나 Esc로 실수로 사라지지 않습니다.

## 광고 수익 준비

- 광고가 일정 추가, 저장, 메뉴 등 조작 버튼 근처에 붙지 않도록 별도 컨테이너를 만들었습니다.
- 광고 영역에는 `광고` 표기를 둡니다.
- 기본값에서는 광고 코드가 전혀 로드되지 않습니다.
- 유효한 AdSense 게시자 ID, 광고 슬롯 ID, 승인된 동의 관리 체계가 모두 준비된 뒤에만 설정으로 활성화할 수 있습니다.
- 개인정보·광고 설정 화면에서 현재 광고 비활성 상태를 확인할 수 있습니다.

## 업로드 전 남은 필수 작업

1. 운영자 및 개인정보 문의 연락처 확정
2. 법률 문서 전문가 검토
3. AdSense 승인 후 실제 게시자·슬롯 설정
4. 필요한 지역에서 Google 인증 CMP 연결 및 동의 철회 기능 확인
5. 최종 모바일·데스크톱 회귀 테스트

## 버전 보존

- 기존 `v1.1.0-legacy`, `v1.2.0`, `v1.3.0` 이력은 그대로 보존합니다.
- 2.0 변경은 별도 `codex/plany-v2.0.0` 브랜치에서 진행합니다.
- 사용자 승인 전에는 원격 GitHub와 현재 서비스에 업로드하지 않습니다.
