# Plany 2.2.0 패치 노트

릴리스 준비일: 2026-07-28  
작업 브랜치: `codex/plany-v2.2.0`

## 한눈에 보기

Plany 2.2는 여행 내부 화면을 원하는 크기로 조절할 수 있게 만들고, 대중교통 경로를 최신 Google Routes API에 연결한 안정화 버전입니다. 여행을 열 때 불필요한 경로 요청을 대량으로 보내던 구조도 사용자 선택형 조회로 바꿨습니다.

## 일정 패널

- 일정과 지도 사이 경계를 마우스로 드래그해 패널 폭을 조절할 수 있습니다.
- 조절한 폭은 브라우저에 저장되어 다음 방문에도 유지됩니다.
- 경계를 두 번 클릭하거나 키보드 `Home`을 누르면 기본 폭으로 돌아갑니다.
- 키보드 좌우 방향키로도 16px씩 조절할 수 있습니다.
- 좁은 화면에서는 지도 공간을 침범하지 않도록 최대 폭을 자동 제한합니다.
- 모바일에서는 기존처럼 지도와 일정이 세로로 자연스럽게 배치됩니다.

## 지도와 경로

- 지도 경로 버튼을 `INFO` 대신 `1→2`, `2→3`처럼 표시해 어느 구간인지 바로 알 수 있습니다.
- 장소가 빽빽해 지도 버튼이 겹치는 경우를 위해 일정 카드에도 정확한 `1→2 교통` 버튼을 추가했습니다.
- 여행 화면 진입만으로 모든 구간의 유료 API를 호출하지 않습니다.
- 사용자가 특정 구간을 눌렀을 때만 대중교통·차량·도보를 조회합니다.
- 같은 조건의 요청은 5분 동안 재사용하며, 결과가 없는 요청은 1분 뒤 다시 조회할 수 있습니다.
- 여러 비동기 응답이 섞여 잘못된 경로 창을 덮어쓰는 문제를 막았습니다.

## 대중교통

- Google Cloud 프로젝트 `maps-481116`의 Routes API를 활성화했습니다.
- 최신 `Route.computeRoutes` 방식으로 노선, 차량 종류, 버스·열차 번호, 방면, 승하차 정류장, 정류장 좌표, 시각, 정류장 수, 배차 간격, 운송사, 환승, 거리, 운임을 처리합니다.
- 현지 사업자가 제공하지 않는 항목은 임의로 만들어 표시하지 않습니다.
- Google이 허용하는 운행시간 조회 범위인 현재 기준 과거 7일~미래 100일을 벗어나면 가장 가까운 유효 시각으로 조회하고 그 사실을 화면에 알립니다.

## 비용 및 안정성

- 장소 16개 일정 기준, 화면 진입 시 발생할 수 있던 구간별 Google 경로 요청을 0건으로 줄였습니다.
- 패널을 드래그하거나 창 크기를 바꿀 때 경로 API가 재호출되지 않습니다.
- 최신 API 장애나 지역별 빈 대중교통 결과가 있을 때만 기존 Directions Service로 자동 전환합니다.
- 최신 API가 특정 지역에서 대중교통 결과를 비워 보내는 경우에도 구형 호환 조회를 한 번 더 시도한 뒤 정보 없음으로 판단합니다.
- API 키나 비밀정보는 새로 추가하거나 변경하지 않았습니다.
- 실제 지도 키는 `yiseowon.github.io/Plany/*`, `127.0.0.1:5500/*`, `localhost:5500/*`에서만 사용할 수 있도록 제한했습니다.
- 사용할 수 있는 API도 Maps JavaScript, Places API (New), Routes API, 지도 중심 계산용 Geocoding API, 장애 시 Directions API 폴백 다섯 가지로 제한했습니다.
- 전용 동의 컬렉션 규칙이 아직 배포되지 않은 환경에서는 기존 사용자 프로필 내부의 본인 전용 쓰기 영역에 동의 버전을 백업해 권한 오류 없이 서버 기록을 유지합니다.

## 배포 상태

- 로컬 버전만 준비합니다.
- GitHub 및 GitHub Pages에는 사용자 승인 전까지 업로드하지 않습니다.

## 검증 결과

- 자동 테스트 30개 통과
- JavaScript 문법 검사 및 변경 공백 검사 통과
- 새 브라우저 세션에서 버전 `2.2.0`, 로그인, 지도, 일정 정렬, 구간 버튼, API 키 제한 확인
- 서울역 → N서울타워 실데이터에서 `버스 402`, 힐튼호텔 승차, 후암약수터 하차, 3개 정류장, 장지공영차고지 방면, 운송사와 정류장 좌표 링크 확인
- 도쿄처럼 제공사가 결과를 주지 않는 구간에서는 차량·도보 대안과 Google 지도 열기 동작 확인
