# Plany 1.2.0 패치 노트

출시 준비일: 2026-07-28
이전 버전: `v1.1.0-legacy`
현재 버전: `v1.2.0`

## 핵심 변화

- 잘못된 날짜, 역순 날짜, 비정상 연도 입력을 차단했습니다.
- 한 여행의 최대 기간을 90일로 제한했습니다.
- 새 여행의 생성·수정 시각을 Firebase 서버 시간으로 기록합니다.
- 중복 Firestore 실시간 구독을 정리했습니다.
- 여행 데이터를 받기 전에 지도를 이동하던 순서 오류를 수정했습니다.
- 일반적인 일정 수정 때 지도가 다시 중앙으로 이동하지 않도록 했습니다.
- 구현이 빠져 있던 지도 경로 정보 버튼을 복구했습니다.
- 여행 소유권과 멤버 목록 변경 권한을 강화했습니다.
- 주요 화면의 사용자 입력을 이스케이프해 코드 삽입 위험을 줄였습니다.
- 화면에 앱 버전을 표시하고 브라우저 탭 아이콘을 추가했습니다.

## 여행 생성과 날짜 검증

- 여행 제목과 여행지를 정리하고 길이를 제한합니다.
- 존재하지 않는 날짜는 저장할 수 없습니다.
- 도착일은 출발일보다 빠를 수 없습니다.
- 2020년부터 2100년 사이의 날짜만 지원합니다.
- 여행 기간은 최대 90일입니다.

> 이번 버전은 날짜 데이터의 정확성을 개선한 버전입니다. 달력 선택 화면 자체를 새로 디자인하는 작업은 다음 UI 버전에서 진행합니다.

## 데이터와 동기화

- 새 여행 문서에 `schemaVersion: 2`를 기록합니다.
- `createdAt`과 `updatedAt`은 `serverTimestamp()`를 사용합니다.
- 로그아웃하거나 여행을 바꿀 때 기존 실시간 구독을 해제합니다.
- 기존 1.1 데이터 구조는 계속 읽을 수 있도록 유지했습니다.

## 보안

- 일반 멤버는 여행 소유자를 변경할 수 없습니다.
- 일반 멤버는 멤버 목록을 임의로 변경할 수 없습니다.
- 방장은 자신을 멤버 목록에서 제거할 수 없습니다.
- 초대 사용자는 자신의 계정만 새 멤버로 추가할 수 있습니다.
- 여행, 장소, 프로필, 체크리스트, 비용 화면의 주요 문자열을 안전하게 표시합니다.
- 위험한 이미지 URL 스킴을 차단합니다.

## 테스트 결과

- Node 자동 테스트 11개 통과
- JavaScript 구문 검사 통과
- 버전 파일 일치 검사 통과
- 정적 HTML 중복 ID 0개
- 누락된 로컬 에셋 0개
- 데스크톱·모바일 초기 화면 로딩 정상
- 브라우저 콘솔 오류·경고 0개
- 모바일 가로 넘침 없음
- SVG 아이콘 문법 검사 통과

## 알려진 제한

- 로그인 이후 생성·수정·초대 전체 흐름은 실제 Firebase 데이터 변경을 피하기 위해 자동 실행하지 않았습니다.
- Firestore 규칙은 정적 불변식 검사를 통과했지만, 현재 맥에 Java 런타임이 없어 로컬 Firebase 에뮬레이터 검증은 실행하지 못했습니다.
- 날짜 선택기는 아직 브라우저 기본 UI이며, 커스텀 기간 선택기는 다음 버전 범위입니다.
